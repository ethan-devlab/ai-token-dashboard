# Historical records

[Current documentation](../README.md)

These dated records retain accepted decisions, reproduced failures and validation evidence. They describe their named checkpoint; they are not the current operating guide. Use the current guides for behavior that changed later. Local PIDs, path literals and service observations are historical. Clickable links follow the new archive layout; literal source paths retain their original checkpoint context. Do not reuse them as live state.
