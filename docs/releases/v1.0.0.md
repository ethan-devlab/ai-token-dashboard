Local AI Token Dashboard reads Codex and Claude Code usage from local JSONL files. It shows token totals, API-equivalent costs, usage trends, and session details. English and Traditional Chinese are available.

### Included in this release

- Codex forks and paginated sessions subtract inherited usage at the recorded history boundary.
- Copied Claude responses are counted once across sessions. New responses still count separately.
- Session directories accept `~/.codex/sessions` and `~/.claude/projects`.
- The detail observation limit is configurable in Settings or `.env`. The default is 2,000; changing it does not limit parsing or totals.
- CI checks Ubuntu on Node 22.15.0, plus Windows and macOS on Node 24.

### Run locally

Use Node 22.15.0+ on 22.x, 23.8.0+ on 23.x, or Node 24+. Extract the ZIP, copy `.env.example` to `.env`, then run `npm start`. Open http://localhost:3333. No package installation is needed.

### Before upgrading

This release restarts version numbering at 1.0.0. It contains the current code, not the old v1 feature set. Existing 2.x and 3.x installations need a manual download because their update checker will not treat 1.0.0 as newer. Keep your existing `.env` when replacing application files, then restart the server.

Costs are token-based API estimates, not subscription charges. Missing history or response identities can leave usage incomplete or potentially duplicated; the dashboard keeps those warnings visible. Claude tool fees are not included.

The assets include the source ZIP, `SHA256SUMS`, and migration notes. To check the ZIP's provenance, run `gh attestation verify ai-token-dashboard-v1.0.0.zip -R ethan-devlab/ai-token-dashboard`.
