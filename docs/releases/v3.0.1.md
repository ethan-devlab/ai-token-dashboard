# v3.0.1

This patch restores Claude historical cost estimates, updates model pricing, and adds the Dashboard favicon.

## Fixed

- Valid pre-archive pricing publications migrate once on writer startup without a network request. Existing v3 archives still require verification; damaged archives require explicit repair.
- Legacy Claude records with missing speed or missing/`not_available` geography retain a standard-rate lower bound when the service tier is explicitly standard. The UI keeps partial-pricing warnings and `≥` markers.
- Dated Claude model names such as `claude-haiku-4-5-20251001` match their retained dotted price family.
- The Provider select aligns with the adjacent header controls.

## Updated

- Bundled official pricing checked on 2026-10-14: GPT-6 Astra, GPT-6.1 Sol, GPT-6 Sol/Luna, current GPT-5.6 rates, and 20 Claude models including Fable/Mythos 5.1 and Opus/Sonnet/Haiku 5.5.
- Per-observation input counts select the applicable context tier: above 100,000 input tokens for Claude Haiku 5.5, and above 272,000 for OpenAI long-context pricing rows. The pricing basis retains both tiers, and price details show the threshold and rates.
- Claude pricing refresh accepts the current official table headings, footnotes, and context-tier rows.
- Dashboard and Settings use a local SVG favicon with the application's mint usage bars.

## Upgrade

Stop the Dashboard before replacing source files. Retain `.env`, local pricing publications, and pricing archives. Restart, reload the browser, then use **Update model prices** for each Provider to publish current official rates. A source upgrade does not overwrite an existing verified pricing publication.

Costs remain API-equivalent estimates, not subscription charges or historical bills. Unknown service tiers, explicit unsupported modifiers, and unconfirmed cache durations remain unpriced. Session files and login credentials are not changed by this release.

## Validation

Release checks cover syntax, server/client/API contracts, pricing archives, legacy accounting, model identities, context-tier boundaries, and favicon delivery. Direct desktop checks confirm August/September Claude estimates, header alignment, price-tier details, and favicon rendering at 16/32/64/128 pixels.
